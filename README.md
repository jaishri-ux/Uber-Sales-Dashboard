
# Uber Trip Analysis Dashboard

## Overview

This project is an interactive Power BI dashboard developed to analyze Uber trip data. The dashboard provides insights into bookings, trip distance, revenue, cancellations, payment methods, and customer behavior.

---

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## Dashboard Features

- Total Bookings
- Total Revenue
- Average Trip Distance
- Average Trip Time
- Booking Status Analysis
- Vehicle Type Analysis
- Payment Type Distribution
- Daily Booking Trend
- Trip Distance Distribution
- Dynamic Filters
- Interactive Visualizations

---

## Dataset

The dataset contains Uber trip information including:

- Date
- Time
- Vehicle Type
- Booking Status
- Payment Method
- Trip Distance
- Pickup Location
- Drop Location
- Revenue
